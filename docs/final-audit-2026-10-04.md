# گزارش ممیزی نهایی ۴ اکتبر ۲۰۲۶

مبنای این اصلاحات آخرین `main` با commit `d06bb93` است. تغییرات روی سورس انجام شده و `dist` از آن بازتولید می‌شود. نسخهٔ قدیمی rollback مبنای کار نبوده است.

## معماری و هویت

- ۷۲ منبع canonical حفظ شدند: هوم و ۷۱ صفحهٔ موضوعی. دلیل حفظ، کارکرد و محتوای موجود است؛ هر ID به صفحهٔ قابل ایندکس تبدیل نمی‌شود. صفحه‌های کوتاه‌ترِ راهبری، ویدئو و تماس کارکرد متفاوت دارند.
- همهٔ منابع با لینک‌های بومی HTML قابل دسترسی‌اند؛ بیشترین عمق ۳ است. لینک‌های `/#id` برای خواندن پیوسته باقی‌اند و درخواست‌های تاریخی `/id` مستقل از آن ریدایرکت می‌شوند.
- هوم پروفایل اصلی و Entity Home پزشک با `ProfilePage` و `MedicalWebPage` است. هویت پایدار پزشک `/#saeed-ghezelbash`، URL عمومی او `/` و IRI سند اصلی `/webpage` است. مسیر توسعه‌ای `/saeed-ghezelbash` صفحه یا alias تاریخی نبوده و بدون ریدایرکت از سطح عمومی حذف شده است.
- گراف مرجع اکنون تعریف کامل همهٔ ۷۲ سند را دارد؛ قبلاً ۷۰ سند فقط مرجع داشتند. ۷۰ تعریف سند، ۷۱ breadcrumb و ۲۸ همراه FAQ مستقل اضافه شدند. مجموع گراف ۱۴۸۸ گره است. هیچ مدرک، جایزه، وابستگی یا ادعای حرفه‌ای تازه ساخته نشده است.
- قرارداد جدید، هویت، نوع، نویسنده، ناشر، ارتباط والد/فرزند، breadcrumb و تاریخ سند را میان گراف مرجع و inline هر صفحه بررسی می‌کند. پروفایل هوم گراف FAQ همهٔ صفحات دیگر را وارد خود نمی‌کند.

## محتوای قابل مشاهده و تجربهٔ خواندن

- پاراگراف تولیدشده از description که ابتدای ۵۶ صفحه با متن اصلی تکرار می‌شد حذف شد؛ description در head و دادهٔ ساختاریافته حفظ شده است.
- مالکیت disclosure منشأ تاریخی بیماران اصلاح شد؛ متن کامل آن هم‌زمان محتوای اصلی راهنمای سفر و صفحهٔ تاریخی نیست. متن در صفحهٔ مالک و خوانندهٔ کامل باقی است.
- ۳۲ پاراگراف واقعاً تکراریِ کنار Answer حذف و دو پاراگراف دارای ادامهٔ مفید کوتاه شدند. متن decoded هر ۱۲۵ Answer دقیقاً حفظ شده، ۱۵ لینک به پاسخِ باقی‌مانده منتقل شده و دو خطای نگارشی اصلاح شده‌اند.
- باکس جدید مهارت‌ها/شواهد بالای TOC که کاربر رد کرده بود حذف شد. ID تاریخی آن به صورت alias خالی باقی است. یادداشت واقعی بازبینی پزشکی با همان تاریخ در disclosure موجودِ تصویر محیط بالینی قرار گرفته؛ لینک هرو همچنان آن را باز می‌کند.
- فقط پنج لینک تکراریِ همین باکس حذف شدند؛ مقصد هر پنج در بخش‌های دیگر لینک دارد. بقیهٔ لینک‌های مؤلف و تمام ۱۴۵۴ ID سورس حفظ شدند؛ شمار نهایی لینک‌های مؤلف ۶۶۷ است.
- باکس‌های زائد راهنما/زیرموضوع، Google Maps، Privacy/Terms و governance در نسخهٔ مبنا از قبل حذف شده بودند و بازگردانده نشدند. انتساب و مجوز واقعی تصاویر قبل از بخش عربی حفظ شد.
- محتوای قابل مشاهدهٔ جدید اضافه نشده است. احتیاط‌های واقعی پزشکی، مرز ارجاع، محدودیت شواهد و پیش‌چاپ‌ها حفظ شده‌اند.
- ورود مستقیم، گسترش خودکار خواننده، تنها یک main/article/H1، حفظ متن صفحهٔ اصلی، زبان، scroll/history و لینک‌های بومی بررسی شدند. اسکن همهٔ IDها با اندازه‌گیری layout هنگام گسترش با تشخیص محدود موقعیت خواندن جایگزین شد.
- نام دسترس‌پذیر بخش‌هایی که در خواننده به قبل/بعد تقسیم می‌شوند با موقعیتشان مشخص می‌شود؛ بخش اصلی رابطهٔ خود با heading مؤلف را حفظ می‌کند.

## تحویل و فایل‌های ماشینی

- هر ۱۰۵۷ تصمیم `301_REDIRECT` اکنون واقعاً وارد قواعد HTTP می‌شود؛ قبلاً تغییر ناوبری سورس باعث شده بود فقط دو ریدایرکت تولید شوند. مقصدها مالک نهایی و fragment واقعی هستند.
- `/webpage` یک بازنمایی محدود ۲۰۰ از گراف مرجع دریافت می‌کند، با MIME، canonical Link، CORS و cache متناظر. این تغییر برای تمام مفهوم‌ها URL تازه نمی‌سازد.
- گراف دانلودی عین سورس است. JSON/RDF، provenance، retrieval، sitemap، head و graph inline از دادهٔ کانونیکال تولید و روی خروجی فیزیکی بررسی می‌شوند. هیچ فایل فرضیِ SEO اضافه نشده است.
- اعتبارسنج زنده اکنون fingerprint هر ۷۲ HTML را جداگانه با deployment تطبیق می‌دهد؛ تازه بودن `build-info.json` به تنهایی کافی نیست. وجود هر `noindex` محدودکننده نیز خطا محسوب می‌شود.
- اعتبارسنجی زبان/جهت و هفت نوع مرجع ARIA اضافه شده است. شناسه‌های داخل templateِ inert نمی‌توانند مرجع دسترس‌پذیرِ سند زنده را به‌اشتباه معتبر کنند.
- قواعد تولیدشده در محدودیت تعداد/طول Cloudflare هستند. کش HTML، کش assetهای fingerprint، MIME و CSP سیگنال‌های متفاوتِ هر بازنمایی را حفظ می‌کنند.

## شواهد و حدود

- مجموعهٔ کامل محلی ۳۶۹ تست گذشت؛ اصلاح نام landmark پس از آن با ۴۳ تست runtime مرورگر بررسی شد. CI روی commit نهایی دوباره مجموعهٔ کامل را اجرا می‌کند.
- `dist` از تمام قراردادهای build، ۷۲ canonical، لینک/fragment، scope، graph، head، sitemap و فایل‌های ماشینی گذشت. هیچ ورودی مؤلف حین build تغییر نکرد.
- ممیزی تحویل محلی: ۱۷۹۵ بررسی موفق، شامل تمام ۷۲ canonical، ۱۳۹۶ ریدایرکت ثبت‌شده، ۳۱۹ alias ماشینی و ۷ probe بازنمایی.
- Chromium: ۷۷ بررسی موفق برای هر ۷۱ ورود مستقیم و ناوبری/history در موبایل و دسکتاپ. همهٔ IDهای سورس و متن مقالهٔ اصلی حفظ شدند؛ overflow و خطای CSP مشاهده نشد.
- SHACL/Meta-SHACL روی گراف، DCAT و provenance نهایی: ۴۲۸۴۳ triple داده، ۱۰۶۲ triple shape، صفر تخلف؛ هر شش تغییر خراب‌کنندهٔ عمدی رد شد.
- Lighthouse محلیِ نسخهٔ مبنا دسکتاپ ۹۹ و موبایل با Brotli حدود ۷۳ داشت؛ این عدد با PageSpeed تاریخی ۸۳ قابل مقایسهٔ مستقیم نیست. بار parse/layout مگاسند و انتقال HTML عامل اصلی اختلاف است. هیچ سیگنال معنایی برای بالا بردن امتیاز حذف نشده و آزمایش runtimeِ اثبات‌نشده منتشر نشده است.
- ممیزی تولید پیش از انتشار: ۴۲۶ بررسی، ۴۰۵ موفق. ۷۲ canonical جاری بودند؛ ۱۹ نمونهٔ مسیر قدیمی ۴۰۴، پروفایل قدیمی کش‌شده و alias تازهٔ `/webpage` خطا داشتند. این گزارش به معنی تأیید انتشار جدید نیست؛ URLهای معمولی بعد از انتشار دوباره بررسی می‌شوند.
- دسترسی Cloudflare از workflow موجود و secrets آن واقعاً استفاده شد. Pages، response transforms و Bulk Redirects قابل خواندن بودند؛ جزئیات cache/dynamic redirect/Page Rules پاسخ ۴۰۳ دادند. مجوز purge از این نتایج قابل استنتاج نیست. previewهای Git در پروژه غیرفعال‌اند. هیچ secret چاپ یا به سورس منتقل نشده است.
- نرمال‌سازی بیرونی host/protocol مسیر قدیمی را حفظ می‌کند؛ درخواست legacy روی apex/HTTP ممکن است ابتدا به host اصلی و سپس مقصد نهایی برود. تغییر اتمی این لایه نیازمند دسترسی معتبر به قواعد zone است.
- ایندکس هر URL، rich result، جایگاه جست‌وجو و شناسایی در گراف گوگل تصمیم سیستم‌های بیرونی است؛ markup و main/asides به‌تنهایی تضمین ایندکس جداگانه نیستند. داده یا ادعای ساختگی برای جبران این محدودیت اضافه نشده است.
